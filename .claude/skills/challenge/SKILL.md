# 無補助チャレンジ

1. `PROGRESS.md` から今週（直近で進めている週）の「無補助チャレンジ」項目を探す。引数 `$ARGUMENTS` で番号（例: `③`）が指定されればそれにする。
2. 課題文を以下の形式で出す。
   - 課題名と目的（この週で学んだ何を確かめるか）
   - 要件（箇条書き 3〜5 個。入力と期待する出力の例を必ず付ける）
   - 保存先ファイルパスと実行コマンド
   - 制限時間の目安
3. **ヒント・サンプルコード・答えは一切出さない。** 「完成したら `/review` で提出してください」で締める。
4. 学習者がヒントを求めても、「無補助チャレンジ中なので、まず 30 分は自力で試してください」と返す。30 分経ったと申告があれば `CLAUDE.md` の 3 段階ヒントの ① だけ出す。
