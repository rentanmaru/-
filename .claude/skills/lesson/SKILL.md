# 今日のレッスンを始める

1. `PROGRESS.md` を読み、`[ ]` のままの一番上の項目を今日のテーマにする。引数 `$ARGUMENTS` に項目番号（例: `1-4`）が渡されたらその項目にする。
2. 最初に「今日の項目・ゴール・所要時間の目安」を 3 行で伝える。
3. 概念を未経験者向けに説明し、10 行以内の最小サンプル（日本語コメント付き）を 1〜2 個見せる。
4. 学習者が自分で書く演習を 1〜3 問出す。保存先のファイルパス（例: `01-js-basics/week1/variables.js`）と実行コマンドを明示する。
5. 「書けたらコードと実行結果を貼ってください」で締め、学習者の返答を待つ。**演習の答えは書かない。**
6. 返答が来たらレビューし、合格なら commit を促し、`PROGRESS.md` にチェックを付けるよう伝える。

`CLAUDE.md` のルール（完成コード禁止・3 段階ヒント・返答フォーマット）に従う。
