株式会社Argano「アシスタントWebエンジニア（実務未経験可）」にエントリーするための学習リポジトリ。
最終目標は **React + TypeScript で作った作品を GitHub に公開し、Claude の補助なしで JS/TS を書けるようになること**。

## Claude（教育エージェント）との約束ごと

「自力で書けるようになる」ために、以下を毎回守る。

1. **Claude は完成コードを書かない。** 概念説明は 10 行以内の最小サンプル（日本語コメント付き）だけ。プロジェクトのコードは必ず自分でタイプする。
2. **詰まったときは 3 段階ヒント。** ① 考え方のヒント → ② 日本語の疑似コード → ③ 該当箇所だけの部分コード。いきなり ③ は出さない。
3. **レビューは「なぜ」を説明する。** 動く／動かないだけでなく、より良い書き方とその理由を伝える。
4. **毎週「無補助チャレンジ」。** 週末にその週の内容を使った小課題を Claude なしで解き、その後レビューを受ける。これが「自力で書ける」の測定指標。
5. **毎レッスン git commit。** Git の必須条件を学習の副産物として満たす。
6. **エラーは自分で読む。** エラー文を貼る前に、まず自分で 1 回読んで仮説を立ててから質問する。

## 1 回のセッションの進め方（約 1 時間）

1. `PROGRESS.md` で今日の項目を確認（5 分）
2. Claude が概念を説明 + 最小サンプル（15 分）
3. 自分で演習を書く。詰まったら 3 段階ヒント（40〜60 分）
4. Claude のレビューを受ける（10 分）
5. `git commit`、`PROGRESS.md` に ✔ と一言メモ（5 分）

週の目安: 平日 2〜3 回 × 1 時間 + 週末 3〜4 時間（作品づくりと無補助チャレンジ）
